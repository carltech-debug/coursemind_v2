# Core Providers

---

## Module

Core Application Providers

---

## Purpose

This module contains application-wide Riverpod providers shared across
multiple CourseMind features.

These providers expose global application state and shared dependencies.

---

## Responsibilities

- Authentication state
- Theme management
- Navigation state
- Storage access
- Global application state

---

## Files

| File | Responsibility |
|------|----------------|
| app_provider.dart | Global application provider. |
| auth_provider.dart | Authentication provider. |
| theme_provider.dart | Theme provider. |
| navigation_provider.dart | Navigation provider. |
| storage_provider.dart | Storage provider. |
