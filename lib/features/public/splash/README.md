# Splash Module

## Purpose

The Splash module is responsible for introducing CourseMind when the application starts.

During this stage the application finishes loading while displaying the CourseMind brand.

## Responsibilities

- Display the startup screen.
- Manage splash state.
- Handle splash timing.
- Prepare navigation to the marketing experience.
